Tarifs

Comment fonctionnent les prix ?
  1. Prix de base — le prix par défaut, appliqué à toutes les nuits.
  2. Prix par date / période (optionnel) — remplace le prix de base uniquement sur les dates que vous choisissez (vacances, événements…).
  3. Réductions — appliquées en dernier, sur le prix final (longs séjours, dernière minute).
Les trois se combinent — ils ne s'annulent jamais.
1 · Prix de base (par défaut)

Appliqué à chaque nuit, sauf celles où vous fixez un prix spécifique (étape 2).

2 · Prix variables selon les dates (optionnel)

Enregistré automatiquement dès que vous cochez — pas besoin du bouton « Enregistrer » plus bas.

Coché : vous pouvez fixer des prix par période (plus bas) ou par date (onglet Calendrier) — ils remplacent le prix de base seulement sur ces dates ; toutes les autres nuits restent au prix de base. Décoché : tout est vendu au prix de base (les prix spécifiques sont conservés mais ignorés). Le prix de base reste toujours actif — cette option ne le remplace jamais entièrement.

3 · Réductions (appliquées en dernier)

S'appliquent sur le prix final, qu'il vienne du prix de base ou d'un prix spécifique. Mettre 0 pour désactiver une réduction — cela ne change pas les autres prix.

Hebdo / mensuel : réduction sur les longs séjours (la mensuelle prime dès le seuil atteint). Dernière minute : réduction si l'arrivée est proche (comble les créneaux vides).

Taxe de séjour

Formule appliquée : min(taux % × prix nuit ÷ pers, plafond) × (1 + additionnelles %), par personne et par nuit.

Équipe ménage

Ils recevront un email automatique à chaque nouvelle réservation (dates d'arrivée et de départ, ménage à prévoir).

Prix par date / période (étape 2)

Fixez un prix pour une période (saison, pont, festival…) ou une date précise. Il remplace le prix de base sur ces nuits-là seulement, et s'affiche sur le calendrier public. Nécessite l'option « Autoriser des prix différents selon les dates » cochée ci-dessus.

Importer un fichier de prix (recommandé)

Chargez directement le fichier de tarifs (.txt ou .csv, une période par ligne — même format que ci-dessous). C'est la méthode la plus simple : aucune limite, aucun copier-coller.

Ou coller une année de prix

Une période par ligne : date_début  date_fin  prix€  [nuits_min]  [libellé]. Dates au format JJ/MM/AAAA ou AAAA-MM-JJ. Séparateurs : espaces, tabulations, virgules ou points-virgules. Exemple :

01/07/2026  31/08/2026  90   2  Haute saison été
24/12/2026  02/01/2027  120  3  Fêtes de fin d'année
14/02/2027  14/02/2027  150     Saint-Valentin
